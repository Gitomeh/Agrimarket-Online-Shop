## Troubleshooting

### Common Issues

**Video too long/short**
- Re-record with adjusted pacing
- Edit sections if comfortable with video editing
- Adjust script segments accordingly

**Audio issues**
- Re-record with better microphone positioning
- Use noise reduction if available
- Consider recording in quieter environment

**Screen visibility issues**
- Increase browser zoom level
- Use larger window size
- Consider recording at higher resolution

**Application issues during recording**
- Have backup deployment ready
- Practice with local development version
- Prepare explanation of technical issues if they occur

**Guardrail not triggering**
- Identify which guardrail to demonstrate beforehand
- Have test data ready that will trigger specific guardrails
- Be prepared to explain what would happen if guardrail triggers
